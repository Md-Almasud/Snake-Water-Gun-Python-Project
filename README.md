# Snake Water Gun Game

A fun, beginner-friendly command-line game built using Python. Play Snake, Water, or Gun against the computer and see who wins!

## Features

-  Random computer choices
-  Interactive user input
-  Win, lose, and draw detection
-  Simple command-line interface

## Game Rules

| Choice | Beats |
| 🐍 Snake | 💧 Water |
| 💧 Water | 🔫 Gun |
| 🔫 Gun | 🐍 Snake |

## What I Learned

- Python functions
- Conditional statements
- User input handling
- Random number generation
- Basic game logic
